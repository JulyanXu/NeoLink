# NeoLink V3 · 2026-09-08

将新能源产业日报升级为产业情报工作台。保持静态部署，无构建工具、第三方运行时或新的后端依赖。

## 产品变化

- 总览：重点阅读、40条去重动态、9个跨栏目主题及新闻来源覆盖。
- 全部动态：搜索、分类、主题、近7/30天和排序可组合；条件写入URL，刷新与浏览器返回可恢复。
- 项目进程：规划/推介（含竞配、备案）、招标/采购、中标/公示、建设/并网和阶段待核。按报道整理，不声称是逐个项目的完成状态。
- 产业链企业：72家归档企业，按7类角色检索；展开资料、102个可访问关系节点及对应来源。快照日期2026-05-15，不伪装成当前资料。
- 数字观察：提取标题中明确的容量、价格、亿元金额，保留“近”“突破”等限定词和完整语境，不合计不同阶段或单位。
- 报道详情：来源、日期、整理依据、原始分类、标题数字、同主题报道。
- 收藏：仅保存在当前浏览器；无账号和云端同步。已移出当前滚动快照的收藏保留标记。
- 所有视图共享浅色/深色样式及移动导航。旧index/news-more/article/enterprise-map地址保留，metric文章地址回到对应报道。
